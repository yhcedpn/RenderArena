# RenderArena

RenderArena 用 C++ 图形编程任务比较模型在渲染算法、资源管理和工程实现上的表现。仓库包含题面规范、各答卷源码与构建配置。

## 项目入口

- [解决方案](RenderArena.slnx)：答卷工程入口。
- [题面规范](Tasks/)：每道题的功能、资源语义与验收标准。
- [Wiki](wiki/Home.md)：评测方式、通用构建命令与项目结构；Vulkan 栏目提供任务和答卷入口，OpenGL 栏目预留。
- [执行规范](AGENTS.md)：测评隔离、工程约定与文档职责；执行测评时同时读取任务目录的 `AGENTS.md` 和题面。
