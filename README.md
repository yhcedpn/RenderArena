# RenderArena

RenderArena 使用图形学编程任务比较模型在渲染算法、资源管理和工程实现品味上的表现。本项目不做区分度极低的 Benchmark 跑分，也不做过于简单的前端 oneshot 或者一般的后端逻辑编写，而是使用难度极高的图形学领域的评测题目，同时涵盖“前端”和“后端”的领域，聚焦模型在实际的复杂中长程任务的表现，以提供更高的能力区分度。
